效用函数与资产配置

从"人为什么厌恶风险"出发，用均值—方差效用函数把收益与风险折算成一个可排序的数值；再在无风险资产与风险资产之间分配资金，用代数与几何两条路径求出最优权重，并落到资本配置线、有效前沿与资本市场线上。

一、风险与风险厌恶

1.1 经济学的基本假设

经济学假设：人厌恶风险，厌恶不确定性。这一假设是整个效用分析框架的起点。

一个直观的例子
资产年初投入年底收回期望收益
资产 A 1 万 1.2 万（确定） 0.2 万
资产 B 1 万 2 万（50% 概率）
0.4 万（50% 概率）		 0.2 万

两者期望收益相同，但 A 的结果确定，B 的结果不确定。大部分投资者喜欢资产 A —— 这就是风险厌恶的直接体现。

1.2 风险厌恶意味着什么

  • 资产的吸引力随着期望收益的增加而增加，随着风险的减少而增加。
  • 要求人承担风险，必须有相应的风险报偿，即更高的期望收益率。
  • 一项有风险的投资，其期望收益率应当高于无风险投资的收益率；高出的部分，称为风险溢价。
问题的引出 如果资产 A 的收益与风险都大于资产 B，怎么比较？—— 收益和风险同向变动时，单看哪一个指标都无法排序，需要引入效用函数。

二、均值—方差效用函数

2.1 函数形式

$$U = E(r) - \frac{1}{2}A\sigma^2$$
其中 $\frac{1}{2}$ 是一个约定俗成的数值。
符号含义
符号含义
$U$效用值
$E(r)$资产或资产组合的期望收益率
$A$风险厌恶系数
$\sigma^2$收益率的方差，度量风险（由于正态分布）

2.2 风险厌恶系数 A 的取值

取值投资者类型
$A > 0$风险厌恶者
$A = 0$风险中性者
$A < 0$风险偏好者

2.3 使用前提与使用方式

前提

均值方差效用函数的前提是收益率为正态分布，在此前提下，方差可作为风险的测度。

用法

对每个投资组合计算效用值，进行排序，可以选出效用最高的组合。

易错点 效用的具体数值不重要，重要的是相对大小。投资者只是想选出效用最大的投资组合，不必纠结 $U$ 的绝对水平。

三、均值—标准差坐标系

把每个组合画在以期望收益率为纵轴、标准差为横轴的坐标系中，可以直观比较：

如果 $E(r_A) \ge E(r_B)$ 并且 $\sigma_A \le \sigma_B$，对于任何投资者而言，投资组合 A 优于投资组合 B。

即：收益不低于对方、风险不高于对方时，无需借助效用函数即可判定优劣。

四、无差异曲线

  • 无差异曲线：效用水平不变时，$E(r)$ 和 $\sigma$ 的关系。
  • 无差异曲线上的每一点，效用相同。
  • 无差异曲线向左上角平移代表效用上升。

在 $E(r)$—$\sigma$ 坐标系中，越靠左上（收益更高、风险更低）的无差异曲线，代表的效用水平越高。

五、资产配置

5.1 什么是资产配置

  • 资产配置是投资组合构建中最重要的问题，决定每个类别的资产的配置比例或权重。
  • 本课程要解决的资产配置问题：在无风险资产和风险资产之间分配资金，建立一个资产组合。

5.2 无风险资产

层次界定
定义 持有期收益率没有不确定性。
严格来说 只有债券期限与持有期限相同的零息国债可以认为是无风险资产。
实践中 投资期限和持有期限相同的大银行的存款也可以认为是无风险资产。

5.3 记号设定

符号含义
$r_f$无风险资产收益率，标准差 $\sigma_{r_f} = 0\%$
$E(r_p)$风险资产预期收益率
$\sigma_p$风险资产的标准差
$y$分配给风险投资组合 P 的资金比例
$1-y$分配给无风险资产 F 的资金比例
C利用风险资产 p 和无风险资产 f 构造出的组合

六、代数求解最优资产配置

6.1 组合 C 的收益率与期望收益率

$$r_C = (1-y)r_f + y\,r_p$$ $$E(r_c) = (1-y)r_f + yE(r_P) = r_f + y\left[E(r_P) - r_f\right]$$

6.2 组合 C 的风险

$$\sigma_C^2 = \mathrm{Var}\left[(1-y)r_f + y r_p\right] = y^2\sigma_p^2$$

因为无风险资产的标准差为 0，且与风险资产不相关，交叉项消失，组合方差只由风险资产部分贡献。

6.3 效用最优化问题

$$\max_y \; U = E(r_c) - \frac{1}{2}A\sigma_c^2 = r_f + y\left[E(r_P) - r_f\right] - \frac{1}{2}A y^2 \sigma_P^2$$

6.4 优化结果

$$y^* = \frac{E(r_P) - r_f}{A\sigma_P^2}$$
分子是奖励（风险溢价），分母是惩罚（成本）（风险厌恶系数 × 方差）。投资者在收益和风险之间进行权衡。
读法 风险溢价越大，投资者越愿意多配风险资产；风险厌恶系数 $A$ 越大、风险资产方差 $\sigma_P^2$ 越大，投资者越倾向于少配风险资产。

七、几何求解最优资产配置

7.1 $E(r_c)$ 与 $\sigma_c$ 的关系

把 $y = \sigma_C / \sigma_P$ 代入期望收益率表达式，得：

$$E(r_C) = r_f + \left[\frac{E(r_P) - r_f}{\sigma_P}\right]\sigma_C$$

上式说明，组合 C 的预期收益率 $E(r_c)$ 和其风险 $\sigma_c$ 成正比，斜率如下：

$$\text{Slope} = \frac{E(r_P) - r_f}{\sigma_P}$$
这个斜率就是风险资产组合的夏普比率。

7.2 资本配置线（CAL）与投资可行集

  • 将 $E(r_C)$ 视为 $\sigma_C$ 的函数，在 $E(r_C)$—$\sigma_C$ 坐标系中画出这个函数的图像，称为资本配置线（Capital Allocation Line, CAL）。
  • 这个函数在图上就是无风险资产和风险资产组合的连线。
  • CAL 也是投资者的投资可行集，投资者只能在 CAL 上选择资产配置。
  • 相当于 budget constraint（预算约束）。

7.3 有效前沿

  • 对每一个给定的预期收益率，方差最小的组合，称为最小方差组合。
  • 在预期收益率和方差的坐标系中，将所有最小方差组合链接起来，称为有效前沿。
  • 在本节的设定下，资本配置线就是有效前沿。

九、资本市场线

  • 无风险资产和市场组合构成的资本配置线（CAL）称为资本市场线（Capital Market Line, CML）。
  • 投资者买入的风险组合为市场组合。
  • 投资者没有进行任何证券分析来选择股票，因此投资者采用的是被动策略。
